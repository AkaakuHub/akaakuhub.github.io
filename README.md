# AkaakuHub

Three.jsで描画する部室を入口にした個人サイトです。室内では位置を固定し、四方の壁・天井・床へ視線を切り替えます。

## 部室

画面下部のボタンで四方の壁・天井・床を選びます。左右の矢印キー・横スワイプで壁を切り替え、上下の矢印キー・縦スワイプで天井と床を向きます。

ホワイトボードの紙はクリック・タップ、または「掲示を見る」で近づきます。「拡大」、マウスホイール、ピンチで実カメラを紙へ近づけ、拡大中はドラッグや矢印キーで紙面内を移動します。Escapeで全体表示に戻り、もう一度押すと部屋へ戻ります。別の紙へ移ると拡大を解除します。

東京の座標から日付と実時刻における太陽の方位・高度を計算し、毎秒更新します。窓は南向きです。晴天を想定した日差しと空色を計算し、夜は天井の面光源で照らします。

散乱光は通常の照明と同じ影マップを参照し、画面の深度から復元した物体の表面まで積分します。Henyey–Greenstein位相関数とBeer–Lambert則を使い、半解像度の計算結果を深度に応じて合成します。[参考にした描画処理](https://github.com/AkaakuHub/steamvr-workshop-tools-win/tree/main/rendering)の原理をもとに、メートル単位の部室用GLSLとして実装しています。

スマホとPCで同じ空間を描画し、画面の実寸に合わせて画角・描画解像度を調整します。

床・壁・木材・布・金具には[Poly Haven](https://polyhaven.com/license)と[ambientCG](https://docs.ambientcg.com/license/)のCC0素材を使い、色・法線・粗さ・金属度を実寸で適用しています。支柱、蝶番、ビス、キャスター、窓やドアの金具も用途別の材質を共有します。素材の出典と著者は[素材一覧](public/materials/attribution.json)に記録しています。参考作品のモデルやテクスチャは使用していません。

## 開発

Node.js 22.18以降とpnpmを使用します。

```sh
pnpm install
pnpm dev
```

## 検証

```sh
pnpm check
pnpm build
```

Vite+、TypeScript、Oxfmt、Oxlint、Knip、Lefthookを使用しています。`dist/`を静的ホスティングに配置できます。
