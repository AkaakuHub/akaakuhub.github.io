# AkaakuHub

Three.jsで描画する部室を入口にした個人サイトです。室内では位置を固定し、四方の壁・天井・床へ視線を切り替えます。

## 部室

画面下部のボタンで四方の壁・天井・床を選びます。左右の矢印キー・横スワイプで壁を切り替え、上下の矢印キー・縦スワイプで天井と床を向きます。

ホワイトボードの紙はクリック・タップ、または「掲示を見る」で近づきます。「拡大」、マウスホイール、ピンチで実カメラを紙へ近づけ、拡大中はドラッグや矢印キーで紙面内を移動します。Escapeで全体表示に戻り、もう一度押すと部屋へ戻ります。別の紙へ移ると拡大を解除します。

卯辰山の緯度36.5732度・経度136.67774度と北方向180度の設定から、日付と実時刻における太陽の方位・高度を計算し、毎分更新します。晴天を想定した日差しと空色を計算します。蛍光灯の直接光と4回までの拡散反射、窓から入る天空光の伝達を部屋の形状から事前計算します。天空光の色と明るさは時刻に合わせて更新します。

散乱光は通常の照明と同じ影マップを参照し、画面の深度から復元した物体の表面まで積分します。Henyey–Greenstein位相関数とBeer–Lambert則を使い、半解像度の計算結果を深度に応じて合成します。[参考にした描画処理](https://github.com/AkaakuHub/steamvr-workshop-tools-win/tree/main/rendering)の原理をもとに、メートル単位の部室用GLSLとして実装しています。

スマホとPCで同じ空間を描画し、画面の実寸に合わせて画角・描画解像度を調整します。

スマホとPCで共通の事前計算した照明と遮蔽を使用します。反射プローブは5分間隔で更新し、操作していない間の連続描画は停止します。

床・壁・木材・布・金具には[Poly Haven](https://polyhaven.com/license)と[ambientCG](https://docs.ambientcg.com/license/)のCC0素材を使い、色・法線・粗さ・金属度を実寸で適用しています。支柱、蝶番、ビス、キャスター、窓やドアの金具も用途別の材質を共有します。素材の出典と著者は[素材一覧](public/materials/attribution.json)に記録しています。参考作品のモデルやテクスチャは使用していません。

画像と照明データは`src/assets/`へ集約し、ビルド時に内容に対応したファイル名で出力します。`manifest.json`には実ファイルのサイズとSHA-256を記録します。材質画像は約2.2MB、照明データは約1.5MBです。最初に小さい起動用モジュールを読み込み、紙の画像と照明データが展開できた時点で部屋の組み立てを始めます。素材が揃った物体から背景へ描画し、細い進捗バーと、準備が進むにつれて晴れるブラーを表示します。

取得・検証・共有・OPFS保存にはnpm版`unified-asset-loader@0.1.0`を使用します。マニフェストのSHA-256を取得元の識別に使い、素材を更新すると対象のキャッシュだけを入れ替えます。進捗は画像の展開とGPUへの転送、照明データの展開が完了した件数から計算します。保存や展開に失敗した場合は読み込みを停止します。

## 開発

Node.js24.22.1以降とpnpmを使用します。HTTPSの証明書と秘密鍵を用意し、Git管理外の`.env.local`へパスを設定します。

```dotenv
DEV_TLS_CERT_FILE=/path/to/development.crt
DEV_TLS_KEY_FILE=/path/to/development.key
```

```sh
pnpm install
pnpm dev
```

アセットを追加・更新したときは、マニフェストを再生成します。

```sh
node scripts/assets/catalog.mjs
```

## 検証

```sh
pnpm check
pnpm build
```

Vite+、TypeScript、Oxfmt、Oxlint、Knip、Lefthookを使用しています。開発・プレビューはHTTPSで配信し、OPFS用Workerに必要なヘッダーを付与します。

本番の配信先にもHTTPSと次のレスポンスヘッダーが必要です。レスポンスヘッダーは配信側で設定します。

```http
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

## 照明の再計算

形状・配置・材質の色を変更した場合は、起動済みの開発サーバーとChromiumを指定して照明データを再生成します。Python側はPlaywrightを使用します。

```sh
uv run --with playwright python scripts/lighting/bake.py --url https://your-development-host:5174/ --browser /path/to/chromium
```

蛍光管の円筒形状と窓をサンプリングし、実際の三角形との交差から直接光と4回までの拡散反射を計算します。反射の方向は半球と照明器具の面から256回、天井は4096回サンプリングし、材質の色・テクスチャ・金属度・カーテンの透過を反映します。蛍光灯の照度と天空光の伝達をそれぞれ頂点ごとのRGB半精度浮動小数点で保存し、gzipで圧縮します。形状と材質の指紋を読み込み時に照合し、古いデータでは起動しません。動く物体の照明は事前計算に含めません。
